# Pet and metric reconstruction options — primary-source check, 2026-09-11

**Practical finding:** I found runnable geometry/animal-shape research and an early-access pet-sizing service, but did not find a publicly documented, commercially cleared, plug-in pet model/API with independently checked neck/chest/back measurement error across dogs. This is a finding from this bounded search, not a claim that no such system exists.

## What to learn and implement

1. Preserve known scale and controlled capture in the current browser prototype. Predicting image landmarks is separate from metric estimation. The new printed reference supplies scale without requiring owners to type their pet's chest/neck/back.
2. A productive next technical experiment is DA3 metric geometry using calibrated camera focal length and a known-size reference to check/correct scale. Compare its recovered body surface with the existing two-view ellipse method. This would run locally or on a future permitted backend, not be placed into the static site as an untested1.4GB model.
3. For dog anatomy beyond visible silhouettes, seek either separately licensed BITE/SMAL priors or a pet shape model trained from cleared animal scans. A beautiful generated animal mesh is not a measurement target.
4. Follow the evaluation discipline of measurement products: standardized landmarks, repeat captures, held-out animals, independent tape/scan ground truth, per-part centimeter errors, and rejection near size boundaries. These are our recommended engineering measures, not claims that the cited products implement all of them.
5. Preserve rejection when scale/anatomy/visibility is insufficient. The supplied gate video is valuable failure-case data; hidden chest surfaces should not be synthesized into confident measurements.
